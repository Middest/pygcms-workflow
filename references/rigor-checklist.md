# Py-GC-MS 严谨性自我复核清单（详细版）

> 用于每个 Py-GC-MS 项目交付前的完整自检。粗查用 SKILL.md §4 总表；本文件是逐项操作指引。
> 原则：**可复现**（脚本产生）、**可审计**（命令留痕）、**方向稳健**（敏感性检查）。

---

## A. 可复现性（Reproducibility）

- [ ] A1. 所有数值表/图由脚本生成，无交互式手改数字
- [ ] A2. 每个脚本命令记录在 `00_design_notes.md` 或分析日志（含参数、输入目录、日期）
- [ ] A3. 输入原始数据（TXT/QGD）未被动过；任何修正走 `corrections.json` 而非直接改文件
- [ ] A4. 脚本版本固定（git commit hash 或 copy 进项目目录）
- [ ] A5. 随机过程（如 bootstrap）设置 seed，结果可重放

## B. TMAH 处理（N 来源严谨性）

- [ ] B1. 6 种 TMAH 副产物已剔除（`TMAH_ARTIFACTS`）
- [ ] B2. 衍生化副产物（氟化酯/TMS）已剔除（`DERIVATIZATION_ARTIFACTS`）
- [ ] B3. **谱检**：运行 `diag_trimethylamine.py`，基峰 m/z 58 峰独立于 NIST 名称剔除（POC BC15 33% 单峰、MAOC BC7.5 14% 案例）
- [ ] B4. 同时运行 `--keep_tmah` 对照组，报告 keep vs removed 两组 R_MP / Other_N
- [ ] B5. N 来源叙事（如"微生物 N 富集"）在剔除后仍成立；否则改写结论
- [ ] B6. 真实 N-甲基土壤化合物（如 N,N,N'-trimethylethylenediamine）与试剂峰区分：看是否只有 m/z 58/59/42 簇 vs 有高分子量碎片

## C. EI 冲突裁决（跨处理一致性）

- [ ] C1. 同 RT 不同 NIST 名称的峰进入 HIGH 冲突列表
- [ ] C2. 用 QGD 原始谱 cosine≥0.85 裁决（非信任 NIST 名称）
- [ ] C3. 裁决输出 UNIFIED（多数票）vs GENUINE_DIFF（真实差异）分类合理
- [ ] C4. **批次假象排查**：检查文件时间戳与总面积——不同批次谱系统性不同会导致伪 GENUINE_DIFF（Bulk 案例：62 冲突 57 GENUINE_DIFF = 批次差异）
- [ ] C5. 跨批次处理结论有显式注记（如"Bulk Short_alkanes 是批次假象，非剂量效应"）

## D. 敏感性分析（结论稳健性）

- [ ] D1. 报告 S0–S4 五场景类组成（S3 推荐为主结果）
- [ ] D2. 关键结论（如"生物炭芳香碳进 POC 不进 MAOC"）在 S2–S4 方向一致
- [ ] D3. 关键类别的 S2-S4 范围报告在正文/附录

## E. 数值对账（Closure Checks）

- [ ] E1. 峰数对账：Raw = SI<70 删除 + 保留（Σ 闭合）
- [ ] E2. 类组成总和 = 100%（重归一化后）
- [ ] E3. 网络指标：平均度 k̄ = 2E/N 精确匹配（若做分子网络）
- [ ] E4. 类组成用峰数（SI≥70，~900）与网络节点数（全部谱，~1050）分别声明，解释差异
- [ ] E5. 交叉验证：化合物级汇总与 FINAL 类级组成的偏差在注释中说明原因（≤37pp 案例：EI 裁决 + 试剂峰剔除）

## F. 统计严谨性

- [ ] F1. 每处理 n=1（单次上机）→ 无 ANOVA / 无 p 值推断
- [ ] F2. 描述性趋势 + 峰级 bootstrap 95% CI（set seed）
- [ ] F3. CI 全重叠 → 明确写"无法区分"，不写"趋势显著"
- [ ] F4. R_MP 定位为"半定量指示"（5/12 类可归因，峰面积≠碳质量，500°C 裂解重组）
- [ ] F5. 术语正确：SOC（非 organic carbon）、CK、BCxx = t/ha、qCO₂ 等（见 user-profile）

## G. 数据语义

- [ ] G1. **0 = 未检出；NA = 峰存在但面积不可靠**（绝不混用）
- [ ] G2. 异常峰（宽峰/过积分/单峰>30%/RT-RI 失配）标 NA 并在过滤日志留痕
- [ ] G3. 未合并异构体；同一 RT 跨处理对齐容差 ΔRT≤0.10 min 声明
- [ ] G4. 未使用内标（如有，说明定量局限）

## H. 交付与写作

- [ ] H1. 正文用 FINAL（人工裁决 + 谱检版本）；补充材料用 deliverable（化合物级）
- [ ] H2. `04_supplementary_notes.md` 包含：完整处理链、0/NA 语义、TMAH 剔除清单（含 m/z 58 试剂峰）、EI 裁决方法、批次注记、n=1 限制
- [ ] H3. Methods 写明：SI 阈值、TMAH 剔除、归一化、网络参数（cosine/TopK/匹配离子）
- [ ] H4. TG-DSC 交叉验证完成（若数据存在），收敛性结论显式
- [ ] H5. 写作中不把批次假象 / 无统计差异的结果表述为处理效应

---

## 使用方式

1. 每个阶段结束过对应门（G0-G9）
2. 最终交付前完整过 A-H 清单
3. 任一未通过项 → 修正并重跑脚本 → 更新清单状态
4. 清单本体存档到项目目录（如 `PY-GC-MS/qa-checklist.md`），随交付物一起提交
